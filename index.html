Short song? GigScript auto-scales the font so the entire song fills the screen without scrolling. Controls disappear automatically — tap to reveal. Long songs that don't fit get a clear notification.

Kort låt? GigScript skaalar automatiskt om typsnittet så att hela låten fyller skärmen utan att rulla. Kontrollerna döljs automatiskt — tryck för att visa. Långa låtar som inte får plats får ett tydligt meddelande.

Kurzer Song? GigScript skaliert die Schriftart automatisch, sodass der gesamte Song den Bildschirm ohne Scrollen ausfüllt. Bedienelemente werden automatisch ausgeblendet — zum Anzeigen tippen. Zu lange Songs erhalten einen klaren Hinweis.

¿Canción corta? GigScript escala automáticamente la fuente para que toda la canción ocupe la pantalla sin necesidad de desplazarse. Los controles desaparecen automáticamente; toca para mostrarlos. Las canciones largas que no caben reciben un aviso claro.

Frequently asked questions Usein kysytyt kysymyksetVanliga frågorHäufig gestellte FragenPreguntas frecuentes

What is ChordPro?
ChordPro is a simple text format for chord charts. Chords are placed in square brackets inline with lyrics: [Am]Today is gonna [G]be the day. GigScript detects ChordPro automatically and displays the chords above the lyrics in amber.
Does GigScript work offline?
Yes, completely. All your songs are stored on your device. You don't need internet access on stage. Cloud sync (Dropbox, Google Drive, iCloud) only runs when you manually press "Sync now."
How does band sync work?
Everyone in the band points GigScript to the same shared folder in their Dropbox, Google Drive, or iCloud. GigScript reads and writes songs and setlists directly to that folder — no servers, no accounts, just files you control.
Can I use GigScript on both iPhone and iPad, and on Android?
Yes. GigScript runs on iOS (iPhone and iPad) and Android. One purchase covers all your iOS devices; the Android version is purchased separately on Google Play. The app is optimized for tablets on both platforms.
What is European H notation?
In Nordic and German notation, B major is written as H (and B minor as Hm), while B♭ is written as B. GigScript supports this convention natively, including transposition — so transposing Hm up a whole step results correctly in C#m, not Cm.
Can I add the same song twice in a setlist?
No — each song can appear only once per setlist. This keeps things simple and avoids confusion on stage. If you need the same song in a different key, transpose it during the performance using the +/− buttons.
What happens when two band members edit the same song?
GigScript detects the conflict using content hashing and shows a clear resolution screen — choose the device version or the cloud version. No data is lost.
What file formats can I import?
GigScript supports .chordpro, .cho, .crd, .txt, and .pdf files — import from your device, from the clipboard, or place them directly in your shared cloud folder. GigScript auto-detects the format.
Can the same song appear twice in a setlist?
No — each song can appear only once per setlist. This keeps things simple on stage. If you need the same song in a different key, transpose it on the fly with the +/− buttons during the performance.

GigScript detects the conflict using content hashing and shows a clear resolution screen — choose the device version or the cloud version. No data is lost.

Mikä on ChordPro?
ChordPro on yksinkertainen tekstimuoto sointutaulukoille. Soinnut kirjoitetaan hakasulkeisiin sanojen sekaan: [Am]Tänään on [G]kaunis päivä. GigScript tunnistaa ChordPro-muodon automaattisesti ja näyttää soinnut sanojen yläpuolella amberilla.
Toimiiko GigScript offline?
Kyllä, täysin. Kaikki kappaleet tallennetaan laitteellesi. Et tarvitse internetyhteyttä lavalla. Pilvisynkronointi (Dropbox, Google Drive, iCloud) toimii vain kun painat manuaalisesti "Synkronointia nyt".
Miten bändisynkronointi toimii?
Jokainen bändin jäsen osoittaa GigScriptin samaan jaettuun kansioon Dropboxissa, Google Drivessa tai iCloudissa. GigScript lukee ja kirjoittaa kappaleet ja setlistat suoraan sinne — ei palvelimia, ei tilejä, vain tiedostoja jotka sinä hallitset.
Voinko käyttää GigScriptia sekä iPhonella, iPadilla että Androidilla?
Kyllä. GigScript toimii iOS:llä (iPhone ja iPad) sekä Androidilla. Yksi ostos kattaa kaikki iOS-laitteesi; Android-versio ostetaan erikseen Google Playsta. Sovellus on optimoitu tableteille molemmilla alustoilla.
Mikä on H-notaatio?
Pohjoismaisessa ja saksalaisessa notaatiossa englanninkielistä B-säveltä vastaa H ja alannettua B♭-säveltä merkitään kirjaimella B. GigScript tukee tätä käytäntöä natiivisti — esimerkiksi transponoinnissa saksalainen Hm (H-molli) transponoituu kokosävelaskeleen ylöspäin oikein C#m:ksi (eikä virheellisesti Cm:ksi).
Voiko sama kappale olla settilistalla kahdesti?
Ei — sama kappale voi esiintyä settilistalla vain kerran. Tämä pitää asiat yksinkertaisina lavalla. Jos tarvitset samaa kappaletta eri sävellajissa, käytä +/− transponointinappeja esiintymistilassa.
Mitä tapahtuu kun kaksi bändiläistä muokkaa samaa kappaletta?
GigScript havaitsee ristiriidan sisältöhashauksella ja näyttää selkeän ratkaisunäytön — valitse laiteversio tai pilvipalveluversio. Mitään ei menetetä.

What is ChordPro?
ChordPro is a simple text format for chord charts. Chords are placed in square brackets inline with lyrics: [Am]Today is gonna [G]be the day. GigScript detects ChordPro automatically and displays the chords above the lyrics in amber.
Does GigScript work offline?
Yes, completely. All your songs are stored on your device. You don't need internet access on stage. Cloud sync (Dropbox, Google Drive, iCloud) only runs when you manually press "Sync now."
How does band sync work?
Everyone in the band points GigScript to the same shared folder in their Dropbox, Google Drive, or iCloud. GigScript reads and writes songs and setlists directly to that folder — no servers, no accounts, just files you control.
Can I use GigScript on both iPhone and iPad, and on Android?
Yes. GigScript runs on iOS (iPhone and iPad) and Android. One purchase covers all your iOS devices; the Android version is purchased separately on Google Play. The app is optimized for tablets on both platforms.
What is European H notation?
In Nordic and German notation, B major is written as H (and B minor as Hm), while B♭ is written as B. GigScript supports this convention natively, including transposition — so transposing Hm up a whole step results correctly in C#m, not Cm.
Can I add the same song twice in a setlist?
No — each song can appear only once per setlist. This keeps things simple and avoids confusion on stage. If you need the same song in a different key, transpose it during the performance using the +/− buttons.
What happens when two band members edit the same song?
GigScript detects the conflict using content hashing and shows a clear resolution screen — choose the device version or the cloud version. No data is lost.
What file formats can I import?
GigScript supports .chordpro, .cho, .crd, .txt, and .pdf files — import from your device, from the clipboard, or place them directly in your shared cloud folder. GigScript auto-detects the format.
